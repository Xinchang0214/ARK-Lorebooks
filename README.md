# ARK-Lorebooks · 明日方舟剧情世界书

ARK-Lorebooks 是由 [Xinchang0214](https://github.com/Xinchang0214) 牵头、团队成员共同创作的《明日方舟》非官方同人项目。我们以游戏的主线、支线和联动剧情为基础，共同整理剧情资料、编写和维护适用于 SillyTavern（酒馆）的世界书。

## 世界书目录

- [主线](./%E4%B8%BB%E7%BA%BF) 收录主线剧情及相关前传。
- [支线](./%E6%94%AF%E7%BA%BF) 按地区、角色或联动主题分类。

选择对应的 JSON 文件，在 GitHub 文件页点击 **Download raw file** 下载原始文件，再通过 SillyTavern 的世界书界面导入。建议按需要启用对应的世界书。条目含有剧情剧透。
